# 首頁區塊管理

後台入口：[首頁區塊](http://localhost:8088/admin/content/homepage_blocks)。原首頁五個區塊已依原順序搬入此清單，既有文案與內容保留。

## 新增文章區塊

1. 在「首頁區塊」按「新增項目」，填區塊標題，類型選「文章卡片」。
2. 「文章來源」選「手動選取／新增文章」。
3. 在「區塊文章」按「選取」，勾選已有文章；或按「新增」直接撰寫文章。
4. 拖曳文章項目調整卡片順序。手動模式依選取順序顯示全部所選的已發布文章，不受自動模式的分類、精選及數量設定影響。
5. 儲存後由行銷主管確認並開啟「顯示此區塊」。新增文章若為草稿，須先到文章中補齊必要欄位及發布日期並發布。
6. 回到區塊清單，使用排序／拖曳調整整個區塊在首頁的位置。

「依分類自動帶入」則依發布日期由新到舊，套用分類、精選及數量設定。既有自動區塊維持原行為。文字、分類輪播、說明卡片及行動按鈕也可與文章區塊一起排序。

## 防呆與權限

- 停用區塊、未發布文章不會顯示；沒有任何可顯示文章的手動區塊會暫時隱藏。
- 同一區塊不能重複選取同一篇文章；不同區塊可共用文章。
- 從區塊移除文章只取消選取，不刪除文章；刪除整個區塊也保留原文章。
- 已被區塊選取的文章需先取消選取才能刪除。
- FAQ 資料沒有獨立文章頁，不提供作為文章卡片選項。
- 標題、網址、錨點、區塊內容及排序仍有中文儲存驗證。圖片每張上限 5 MB。
- 行銷主管可管理並啟用區塊。文章編輯可建立及修改停用區塊、依既有文章權限撰寫草稿，不能自行啟用區塊。唯讀人員僅查看。

## 前台更新

本機開發站重新整理即可看到區塊排序與新發布文章；正式站仍是靜態輸出，需完成既有建置／發布流程才會更新。

若排序後看起來沒有變動，先確認該區塊已啟用，且「手動選取」模式至少選入一篇已發布文章。沒有文章或只有草稿時，整個區塊會隱藏，即使排第一也不會顯示。若希望自動顯示某分類文章，請選「依分類自動帶入」並設定分類。清單欄位的升冪／降冪只改變後台檢視；請拖曳項目或修改項目內的「排序」並儲存。

首頁「頁面管理」內的舊 JSON 區塊欄位已隱藏，避免同時編輯兩份資料；其他頁面繼續使用原有區塊功能。「顯示區塊」總開關仍在首頁頁面設定中。

## 維護

- 初次建立／補齊模型：`node directus/setup-homepage-blocks.mjs`。完整 `directus:setup` 也會執行。
- 遷移旗標：首頁的 `homepage_blocks_enabled`。原 JSON 保留供回復參考；重跑設定不會重建使用者已刪除的區塊。
- 後台：`homepage_blocks` 與 `homepage_block_articles`；後者只存關聯與排序，移除關聯不刪除文章。
- 複合唯一索引防止重複文章；啟用區塊的自訂錨點也有唯一索引。Hook 更新後需重啟 Directus。
- `node --test scripts/homepage-blocks.test.mjs`：選取排序、草稿隱藏、舊模式及欄位驗證。
- `node scripts/test-homepage-blocks-live.mjs`：臨時帳號／資料驗證新增文章、選取、排序、即時前台與權限，測試後清除。
