# 後台基本操作手冊

本手冊供日常內容編輯使用。登入後台後，所有變更都要按右上角的「儲存」才會寫入；離開頁面不會自動儲存。

## 先理解兩種內容

| 後台名稱 | 用途 | 前台結果 |
| --- | --- | --- |
| 攻略文章 | 攻略、技巧、比較、新手指南等獨立內容 | 產生獨立文章頁，例如 `/guide/文章網址/` |
| 網站頁面 | 首頁、遊戲規則、FAQ、活動等固定版型頁 | 使用指定頁面網址，例如 `/rules/` |

## 新增攻略文章

1. 開啟「攻略文章」，按「新增項目」。
2. 未完成時，狀態維持「暫存文章（草稿）」並儲存；草稿不會顯示在前台。
3. 完成後填寫標題、文章網址、分類、摘要、內文與發布日期。
4. 內文圖片按「插入圖片」，從檔案庫選取或直接上傳；系統會在游標位置自動插入圖片，不必自行輸入 Markdown 圖片語法。替代文字必填。
5. FAQ 有新增項目時，問題與答案都要填寫。
6. 確認無誤後才改為「已發布」。

發布文章需要完整資料；欄位下方的中文錯誤訊息會指出缺少或格式錯誤之處。已發布文章不要改回草稿，否則下一次網站建置會使它下架。

## 編輯網站頁面

1. 開啟「網站頁面」，選擇既有頁面或按「新增項目」。
2. 填寫標題、摘要、頁面類型與網址；網址需以 `/` 開頭及結尾，例如 `/rules/`。
3. 首頁網址是 `/`，不可改網址、下架或刪除。
4. 已發布頁面如要改網址或下架，先確認導覽、按鈕與其他內容沒有引用它。

## 管理首頁區塊

在「首頁區塊」可調整首頁內容與排序。拖曳整個區塊可改變首頁顯示順序。

| 區塊類型 | 主要設定 | Markdown 內容 |
| --- | --- | --- |
| 文章卡片 | 選手動文章，或依分類自動帶入 | 不需要，欄位會隱藏 |
| 圖片輪播 | 至少兩張圖片、每張替代文字／大標／說明、輪播設定 | 不需要，欄位會隱藏 |
| 分類輪播 | 分類設定與顯示文案 | 不需要，欄位會隱藏 |
| Markdown | 自訂文字內容 | 需要填寫 |

- 區塊要出現在前台，需開啟「顯示此區塊」。
- 手動文章卡片至少要選到一篇已發布文章；移除文章只取消首頁選取，不會刪除原文章。
- 圖片輪播啟用前至少兩張圖，圖片需填替代文字、大標與說明；前台可由訪客暫停／播放。
- 圖片檔每張上限 5 MB。

## 圖片與檔案

1. 到「檔案庫」上傳或管理素材。
2. 輪播圖片請放到「網站公開素材」資料夾，才能供首頁輪播選取。
3. 攻略文章可由內文的「插入圖片」直接上傳或選取。
4. 正在被內容使用的檔案不可直接刪除；先到對應文章、頁面或區塊更換圖片。

資料庫儲存的 Directus 圖片使用 `/assets/檔案-UUID` 相對路徑。日後變更前台或 Directus 網域時，不需逐篇修改文章；只要更新部署環境的 `DIRECTUS_URL` 並重新建置前台。

## 導覽、全站設定與轉址

- 「導覽項目」：管理選單連結與順序。連到網站頁面時，該頁面必須已發布。
- 「網站全域設定」：網站名稱、預設圖片、分類、頁尾與浮動按鈕；這是全站共用設定，儲存前需填妥必填欄位。
- 「Redirects」：只建立站內 301 轉址。已發布文章改網址時，系統會保護並建立對應規則；不要手動建立指向自己或循環的轉址。

## 儲存、發布與網站更新

1. Directus 儲存只更新 CMS 資料庫。
2. Railway 後台會立即保留這些內容，但目前前台為靜態網站。
3. 因此已發布的內容要顯示在公開前台，仍需重新建置與部署前台。
4. 部署前確認草稿未誤發布、圖片可讀取、連結有效；發布後再檢查前台頁面。

## 常見問題

**儲存被阻擋？**

查看欄位旁的中文錯誤訊息。常見原因是發布文章缺少摘要／日期／內文、圖片缺少替代文字、輪播少於兩張圖，或網址格式錯誤。

**已儲存但前台沒變？**

先確認內容已發布、首頁區塊已啟用、文章卡片選到已發布文章；再重新建置並部署前台。CMS 儲存不會自行發布靜態網站。

**後台名稱或欄位沒有更新？**

使用 `Cmd + Shift + R` 強制重新整理；必要時登出再登入，以更新 Directus 管理介面的快取。
